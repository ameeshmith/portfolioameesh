# Ameesh Mithanthaya — Developer Portfolio

Personal developer portfolio website showcasing engineering projects, agentic workflows, RAG systems, and professional experience.

Live at: [ameeshmith.github.io](https://ameeshmith.github.io/) (or deployed custom domain)

## Tech Stack
- **Framework:** React 19 + Vite 8 + TypeScript
- **Styling:** Tailwind CSS v4 (dark mode by default)
- **Icons:** `lucide-react`
- **Animations & Interactivity:** Modern UI with Linear/Raycast minimalist aesthetic

## Core Projects Featured
- **Fora AI:** Autonomous Research & Intelligence Engine (Python, LangGraph, MCP, FastAPI, SQLite, Docker)
- **Smart News Synthesizer:** Indian Patent Published News Verification & Summarization System (FastAPI, React, RAG, BERT, FAISS)
- **Pharma Watch:** Drug Adverse Event Trend Analyzer (Streamlit, SQLite, Pandas, Plotly, FAERS ETL)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ameeshmith/portfolioameesh.git

# Navigate to project directory
cd portfolioameesh

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
npm run preview
```
